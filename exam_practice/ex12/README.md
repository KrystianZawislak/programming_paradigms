## Task

### 🇵🇱 Treść zadania (PL)

Napisz program tworzący listę lat przestępnych z przedziału podanego z klawiatury (wczytujemy dwie wartości: rok początkowy i końcowy).

Przypominam, że rok jest przestępny, jeżeli jest podzielny przez 4, ale nie jest podzielny przez 100, chyba, że jest podzielny przez 400.

Listę proszę stworzyć z użyciem list comprehension.

Poprawność proszę sprawdzić podając przedziały 2090-2110 - rok 2100 nie ma się pojawić (nie będzie przestępny), oraz 1590-1610 - rok 1600 ma się pojawić (był przestępny).

### 🇬🇧 Task description (EN)

Write a program that creates a list of leap years in a range given from the keyboard (we read two values: the start year and the end year).

Remember that a year is a leap year if it is divisible by 4 but not divisible by 100, unless it is divisible by 400.

Create the list using a list comprehension.

Check the correctness with the ranges 2090-2110 - the year 2100 must not appear (it will not be a leap year), and 1590-1610 - the year 1600 must appear (it was a leap year).
