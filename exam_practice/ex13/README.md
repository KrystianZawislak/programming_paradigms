## Task

### 🇵🇱 Treść zadania (PL)

Napisz program, który zamieni napis zawierający numer telefonu (np. '600-300-900') na napis 'słowny' (np. '12-34' na 'jeden dwa trzy cztery '). Znaki inne niż cyfry (np. myślniki i spacje) należy pomijać. Należy wykorzystać słownik zawierający liczebniki ('zero', 'jeden', itd). Odwołania do słownika proszę robić odwołania jak do tablicy (nawiasami [ ] ) a nie metodą get.

Program na koniec ma wypisać stworzony napis (nie listę).

Proszę nie używać isdigit

Przydatne:
- `""` lub `''` - pusty napis (np. `napis = ""`)
- `in` - operator który zwraca wartość logiczną czy element znajduje się w liście, krotce, itd. (np. `if element in lista`)

### 🇬🇧 Task description (EN)

Write a program that converts a string containing a phone number (e.g. '600-300-900') into a string 'in words' (e.g. '12-34' into 'one two three four '). Characters other than digits (e.g. dashes and spaces) should be skipped. Use a dictionary containing the numerals ('zero', 'one', etc.). Access the dictionary like an array (with [ ] brackets), not with the `get` method.

At the end, the program should print the created string (not a list).

Do not use `isdigit`.

Useful:
- `""` or `''` - an empty string (e.g. `string = ""`)
- `in` - an operator returning a boolean telling whether an element is in a list, tuple, etc. (e.g. `if element in list`)
