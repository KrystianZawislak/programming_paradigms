## Task

### 🇵🇱 Treść zadania (PL)

Napisz program pobierający z klawiatury liczbę (od 1 do 12) i wypisujący na ekran odpowiedni miesiąc. Przy czym dla 1 wypisujemy styczeń, 2 - luty itd. natomiast dla 7 i 8 ma być wypisane WAKACJE! Dla innych wartości ma być wypisywany komunikat, że to nie jest poprawna wartość

Należy użyć instrukcji match. To ma być jedyna instrukcja wyboru (nie wolno stosować if-else). Nie wolno też stosować pętli.

W programie ma być tylko jedna instrukcja ze słowem WAKACJE

### 🇬🇧 Task description (EN)

Write a program that reads a number (from 1 to 12) from the keyboard and prints the corresponding month. For 1 we print January, for 2 - February, etc., but for 7 and 8 it should print HOLIDAYS! For other values a message that it is not a valid value should be printed.

Use the `match` statement. It must be the only selection statement (if-else is not allowed). Loops are not allowed either.

There may be only one statement with the word HOLIDAYS in the program.
