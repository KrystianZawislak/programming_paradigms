## Task

### 🇵🇱 Treść zadania (PL)

Napisz program, który stworzy tablicę dwuwymiarową przy użyciu list - tak aby można się było odwołać do elementu takiej tablicy jak np. w C (pierwszy element - `tab[0][0]`). Niech "tablica" ma rozmiar 4x6 i niech zostanie utworzona jednym poleceniem wypełniającym ją jednocześnie zerami. Następnie należy wypełnić tablicę sześcianami kolejnych liczb całkowitych począwszy od 1 i wypisać.

### 🇬🇧 Task description (EN)

Write a program that creates a two-dimensional array using lists - so that an element of the array can be accessed like e.g. in C (the first element - `tab[0][0]`). Let the "array" have the size 4x6 and let it be created with one statement that fills it with zeros at the same time. Then fill the array with the cubes of consecutive integers starting from 1 and print it.
