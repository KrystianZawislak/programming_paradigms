## Task

### 🇵🇱 Treść zadania (PL)

Napisz drugą wersję programu z zadania 4, która zamiast zliczać litery 'O' i 'o' wypisze ich położenia (indeksy). Należy użyć pętli for BEZ range. Ponadto w programie nie może wystąpić żadne działanie arytmetyczne (dodawanie, odejmowanie ...) - podpowiedź: enumerate.

### 🇬🇧 Task description (EN)

Write a second version of the program from [exercise 4](../ex4/) which, instead of counting the letters 'O' and 'o', prints their positions (indexes). Use a `for` loop WITHOUT `range`. Moreover, no arithmetic operation (addition, subtraction ...) may appear in the program - hint: `enumerate`.
