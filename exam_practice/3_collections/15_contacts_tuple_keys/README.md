## Task

### 🇵🇱 Treść zadania (PL)

Dany jest "spis kontaktów" w postaci słownika:

```python
kontakty = {('Anna', 'Zielińska'):"501202303", ('Marek', 'Wiśniewski'):"698777111" , ('Ewa', 'Zielińska'): "722444555"}
```

Wypisz numer telefonu Marka Wiśniewskiego (jednym printem - używając słownika).
Napisz kod, który wypisze (używając pętli, przechodzącej po całym słowniku) numery telefonu obu Zielińskich.

### 🇬🇧 Task description (EN)

A "contact list" is given as a dictionary:

```python
contacts = {('Anna', 'Zielińska'):"501202303", ('Marek', 'Wiśniewski'):"698777111" , ('Ewa', 'Zielińska'): "722444555"}
```

Print Marek Wiśniewski's phone number (with one `print` - using the dictionary).
Write code that prints (using a loop going over the whole dictionary) the phone numbers of both Zielińskas.
