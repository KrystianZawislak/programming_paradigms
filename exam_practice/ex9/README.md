Napisz program znajdujący wszystkie możliwości złożenia 50zł z nominałów 1, 2 oraz 5 zł. Należy wypisać liczbę możliwych kombinacji.

Write a program that finds all the ways to make 50 zł from 1, 2 and 5 zł coins. Print the number of possible combinations.
