## Task

### 🇵🇱 Treść zadania (PL)

Napisz program, który policzy (i wypisze) ile, w napisie wprowadzonym z klawiatury, znajduje się liter 'o' i 'O' (łącznie - wynikiem ma być jedna liczba). Użyj pętli for. W zadaniu może tylko raz wystąpić instrukcja if. NIE WOLNO używać range, lower ani count.

### 🇬🇧 Task description (EN)

Write a program that counts (and prints) how many letters 'o' and 'O' there are in a string entered from the keyboard (together - the result should be one number). Use a `for` loop. The `if` statement may appear only once in the program. You MUST NOT use `range`, `lower` or `count`.
