## Task

### 🇵🇱 Treść zadania (PL)

Napisz program znajdujący (i wypisujący) wszystkie liczby pierwsze z zakresu 100-200. Wykorzystaj dwie pętle for z czego jedna ma być typu for-else.

### 🇬🇧 Task description (EN)

Write a program that finds (and prints) all prime numbers in the range 100-200. Use two `for` loops, one of which must be a for-else loop.
