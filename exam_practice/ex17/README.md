## Task

### 🇵🇱 Treść zadania (PL)

Napisz funkcję, która otrzymuje napis zawierający słownie opisaną liczbę z zakresu 60-99 (np. 'siedemdziesiąt trzy') i zamienia ją na 'prawdziwą' liczbę całkowitą (73). Wykorzystaj słownik. Może być przydatna metoda split (`napis.split()`) dzieląca napis na wyrazy.

### 🇬🇧 Task description (EN)

Write a function that takes a string containing a number in the range 60-99 written in words (e.g. 'seventy three') and converts it into a 'real' integer (73). Use a dictionary. The `split` method (`string.split()`), which splits a string into words, may be useful.
